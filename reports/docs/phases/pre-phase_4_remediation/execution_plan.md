# Pre-Phase-4 Remediation — Execution Plan (Wave A–C)

*ACRAS · Extracted from [`remediation_plan.md`](remediation_plan.md) §5 · v1.3 · 2026-10-23.*
*Measure-only evidence gathering; time-boxes are caps, not forecasts. No Tier 1 retrain, feature-handling change, promotion-gate change, or provider-model swap is authorized by this plan.*

## 1. Wave A · Establish evidence and close fast hygiene

Hard time-box: **6.0 hours total / 1 working day (caps, not forecasts)**. Execute `W-A1` through `W-A8` in priority order below. Output: reproducible evidence tables/artifacts, the R-15 non-mutating test fix, and bounded options; no model freeze/retrain, feature change, or provider-config change is authorized by measurement alone.

### 1.1 Wave A execution rules (owner conditions, 2026-10-20)

- **Measure-only.** No Tier 1 retrain, feature-handling change, promotion-gate change, or provider-model swap inside Wave A.
- **Stop rule.** If `W-A5`, `W-A6`, or `W-A7` shows a Tier 1 retrain is needed, stop and return a decision with the evidence. If `W-A1` finds a near-term `gemini-2.5-flash` deprecation or unverified duplicate rates, stop and return an ADR-034 decision. Never extend a time-box to finish a task: on expiry, report the partial evidence and what remains unknown.
- **Evidence is not authorization.** A finding that implies a change is recorded as an option; it does not trigger the change.
